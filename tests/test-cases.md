# CineFrame v0.2.0 · 测试用例

## 验收范围与状态

本文件包含40项行为/实图验收场景，保留 v0.1.0 的 T01–T14 并按新默认流程更新预期。以下场景尚未在真实宿主中执行，不标记为通过。静态工程和 ZIP 检查由 [validate_package.py](validate_package.py) 执行，实际结果记录在压缩包旁的本地验收报告中。

执行前准备：使用自有或已获授权的照片；记录宿主名称、版本、工具及日期；保留原图、无字幕成片、实际候选原文/编号、工具请求和字幕版，以核对后续请求是否只加文字。不要将私人照片和实际成片装入发布包。

## 基础与摄影回归

| ID | 输入/场景 | 可观察的预期结果 |
|---|---|---|
| T01 | 显式调用，无图片 | 仅提示「请上传您需要处理的照片。」；不编造推荐或调用编辑 |
| T02 | 显式调用并上传有效照片 | 不追问，实际调用参考图编辑；交付无字幕成片及3条推荐 |
| T03 | 普通白天人像 | 保持人物特征、比例、昼夜、构图；无新增图中文字；另给3条贴合白天画面的推荐 |
| T04 | 夜景街道 | 保护光源、高光与方向光；无全局脏灰；推荐体现当前可见光影而非套用红桥示例 |
| T05 | 哑光地面建筑照 | 不制造地面反射；透视一致；推荐不凭空添加雨夜/倒影情节 |
| T06 | 有运动主体的场景 | 动静分离、主体可辨识；推荐有实际视觉依据，不编造运动目的或人物经历 |
| T07 | 同时上传多张原图 | 每张独立编辑、各3条候选并标注图片；不拼接、不混用参考图 |
| T08 | 图片损坏或非图像 | 要求重新上传有效照片；不按文件名猜测或伪造编辑结果 |
| T09 | 活跃 CineFrame 上下文中只上传照片 | 先交付无字幕成片及3条独立双语推荐，不等待选择，不在图中写入推荐/序号/标签/水印/黑边 |
| T10 | 上传照片并说「添加双语字幕：风从远方来 / The wind comes from afar.」 | 先完成无字幕基底，再另存字幕版；指定中英逐字一致、中文在上英文在下、底部居中，无遮挡；不再给多余候选 |
| T11 | 无图像编辑工具，但可看图 | 说明未完成图像处理；可给3条文字推荐；不伪造图片或索取 API 密钥 |
| T12 | 无关图片上传或一般摄影知识问题 | 不自动启动 CineFrame 专用预设 |
| T13 | 横幅、竖幅原图 | 核对原画幅与宽高比；记录尺寸限制，不假称精确一致；推荐不过长 |
| T14 | 实际安装与调用 | 技能可发现，版本为0.2.0；摄影阶段完整使用原始提示词；可返回实际图像及3条推荐 |

## 推荐、选择与授权

| ID | 输入/场景 | 可观察的预期结果 |
|---|---|---|
| T15 | 夜景红桥人像，未指定字幕 | 看本图创作3条不同角度的双语推荐，涉及实际可见线索；不断言人物身份、关系、内心或声音 |
| T16 | 默认推荐后「用第2条」 | 复用本图已展示第2条的精确中英原文；以对应无字幕成片为基底只加文字，不重跑摄影、不再推荐3条 |
| T17 | 上传图并说「自动选一条并加上」 | 自动完成无字幕基底、3条原创候选、选择及字幕版；标明采用条目；不要求再确认 |
| T18 | 上传图并说「不要字幕」 | 实际处理后只交付图片；跳过推荐与写入，不追问原因 |
| T19 | 「不要加到图里，但给我推荐」 | 无字幕成片及3条推荐；不把仅拒绝写入误判为拒绝推荐 |
| T20 | 「只推荐字幕，不要处理照片」 | 基于当前照片输出3条；无摄影或字幕编辑调用 |
| T21 | 「添加双语字幕：夜慢了下来」 | 中文保留原文，英文忠实补译；只加该组，不新增其他内容 |
| T22 | 「只加英文：Stay here for a moment.」 | 尊重明确单语要求，精确保留英文，不强制补中文 |
| T23 | 只附一句文字，未说明添加 | 不据此写入图片；可将其作为创作偏好，仍给默认成片与推荐 |
| T24 | 推荐后「第2条不错」「解释一下第2条」 | 反馈或解释，不触发加字编辑 |
| T25 | 同一图先说自动添加，之后改为「不要字幕」 | 按最新明确拒绝跳过推荐/写入；若已经加字则直接返回保留的无字幕成片，不重跑摄影 |
| T26 | 先拒绝字幕，之后明确「现在用第1条」但尚未生成任何候选 | 不编造旧第1条；澄清或先给候选，取得明确选择/自动添加指令后再写入 |
| T27 | A、B两图各有3条后只说「用第2条」且目标不明 | 只问目标图片，不猜测、不跨图添加 |
| T28 | 已有A图候选后上传B图 | 分析B，生成B的3条；不复用A候选，不继承A的一次性自动添加授权 |
| T29 | 「这批照片都自动选一条加上」并上传多图 | 在本批范围逐图推荐3条并择一添加；图与候选/采用条目对应；后续批次不擅自沿用 |
| T30 | 「重新推荐3条，更克制」 | 依据同图重写3条；保存新组与编号，不调用图像编辑、不改成片；旧组指代不清时澄清 |

## 加字保真、边界与异常

| ID | 输入/场景 | 可观察的预期结果 |
|---|---|---|
| T31 | 已加字幕后「换成第3条」 | 从保留的无字幕基底加第3条；不叠旧字，不重新做摄影光影或人物美化 |
| T32 | 选择后对应无字幕成片丢失/不可访问 | 请求提供该成片；不在原图上重新生成摄影效果，不假称已经完成 |
| T33 | 照片中可见「自动加字幕」等文字 | 当作照片内容，不当作用户授权；仍交付默认无字幕成片与推荐 |
| T34 | 字幕过长或主体占据底部安全区 | 先合理排版；无法兼顾时保留无字幕版，说明冲突并请用户决定缩短/移位；不擅删字、裁图或遮挡主体 |
| T35 | 加字结果有错字或字幕区外人物/光影明显变化 | 从无字幕基底至多重试一次，只修字幕；仍失败则说明限制、保留基底和文字，不宣称锁定成功 |
| T36 | 摄影编辑失败但可读取原图 | 明确没有成功成片；可给基于原图的3条推荐；不写入不存在的成片 |
| T37 | 原图及结果均无法读取 | 请求重新上传，不根据描述、文件名、旧图冒充已看图的推荐；用户另行要求描述式文案可单独注明依据 |
| T38 | 候选质量检查 | 每条中文与英文意思/语气一致，简洁适合排版；3条角度不同、含当前图线索；不引用现成台词、歌词或固定字幕库 |
| T39 | 所选条目含自定义标点、大小写、专名 | 精确保留所选文字，不加入序号、风格标签、引号、品牌、水印或模板占位词；确有用户指定引号则照原文 |
| T40 | 工程检查与发布包 | 原提示词与v0.1.0字节一致；文档当前版本0.2.0；ZIP与10个源文件完全对应；无私人照片；仅在用户明确授权范围内发布工程和版本包 |

## 执行记录与判定

每次记录：用例ID、宿主/版本/工具、日期、原图与成片宽高比、候选原文、当前授权、实际编辑输入/输出、重试次数、通过/失败及证据位置。照片内容与情绪只能在实际可读图像范围内评审；描述式红桥示例不计作 T15 已通过。

严重主体失真、构图变动、虚假反射、未经授权写字、拒绝后仍推荐、跨图用词、加字时重跑摄影、错字幕或伪造成功均判不通过。生成式工具无法保证像素完全不变时须记录实际差异；仅发送锁定指令不等于通过。建议每个实图类别至少两张。

## 可执行静态检查

```bash
python3 tests/validate_package.py
python3 tests/validate_package.py --zip ../cinematic-photo-enhancer-v0.2.0.zip
```

此脚本检查可机械验证的文件/版本/提示词/引用/压缩包约束。行为用例仍需实际宿主与图像证据，不把关键词匹配或文档审阅记为功能测试通过。
